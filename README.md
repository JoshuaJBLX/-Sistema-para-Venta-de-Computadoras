## Ejecución del Script de Base de Datos
1. Instalar MySQL/MariaDB.
2. Ejecutar `sql/ddl.sql` para crear tablas.
3. Ejecutar `sql/dml.sql` para insertar datos de prueba.
4. (Opcional) Configurar API Node.js + Express según /routes.
